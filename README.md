# 🏜️ Desert Dash

**Desert Dash** is a 2D endless runner game built using **C++** and **Allegro 4**.  
The player controls a camel running through a desert, jumping over cacti, collecting coins, and trying to survive as long as possible while the difficulty gradually increases.

---

## 🎮 Gameplay

- Press **ENTER** to start the game
- Press **SPACE** to jump
- Avoid cactus obstacles 🌵
- Collect coins to increase your score 🪙
- You have **3 lives ❤️**
- The game ends when all lives are lost

---

## ✨ Features

- Smooth character animation (multiple frames)
- Collision detection system
- Coin collection system with scoring
- Lives system with heart indicators
- Screen shake effect on collision
- Simple physics (gravity + jump)
- Endless runner mechanic
